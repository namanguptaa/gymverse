# Changelog

All notable changes to GymVerse are listed here. Versions follow [Semantic Versioning](https://semver.org).

## 1.0.0 (2026-11-23)

First public release.

### Added

- Self-hosted server on Node.js with built-in SQLite and zero npm dependencies
- One-command installers for macOS, Linux (`install.sh`) and Windows (`install.ps1`)
- Prebuilt multi-architecture Docker image on GitHub Container Registry, published automatically
- First-run owner setup with optional sample gym data, and one-tap clearing of sample data
- Sign-in, password change and command-line password reset
- Attendance with check-in and check-out, automatic check-out and past-day editing
- Membership plans, renewals and fee tracking
- WhatsApp and SMS reminders with editable templates
- Workout routines, exercise library, workout log, personal records and body weight
- Member profiles, reports, peak hours and closed days
- Multi-device sync, offline outbox, daily backups, backup restore and Excel export
- Configurable branding and an About panel with a link to the source code
